# 知识核心与宿主接入

知识内容由独立 `neux-knowledge` 核心维护。NeuxAlly 保存连接和库模型偏好，资料整理通过 Runtime 的独立文本生成接口调用 CLI。后台整理任务不创建伙伴、Chat 或 Execution，不写聊天 JSONL；用户主动发起的 Wiki 修订复用普通 Chat 与 Execution。知识库列表与各库详情使用独立标签页，详情按后端、连接与库身份区分；同一库的文档、Wiki 和图谱复用该详情标签。库内通过 Dock 切换文档、Wiki 与图谱，保留创建、文档上传与手动整理；文档原件通过列表弹窗查看。

## 统一操作适配

`desktop/src/shared/api/knowledge` 是知识库页面的 HTTP 适配边界。本地与远端实现提供同一组库、资料、目录、页面、历史、任务与配置操作；所有请求固定完整后端、连接和库身份，调用方的路径不能改写目标。Query 管理服务器事实，Adapter 只拥有协议转换和能力检查，不建立知识内容副本。

入口同步固定身份与静态实现策略，完整方法表通过类型检查核对本地／远端合同；协议实现在首次异步操作时加载。整理冻结输入独立于执行模块，删除器在首次操作时加载并保留同一实例，页面 Shell 和可用控件不等待这些模块。

远端能力分别保留协议支持、主体权限及当前条件。官方合同允许的读取仍交由服务器逐次授权；未支持的操作保留入口，点击显示“远端能力未支持”。权限不足、执行配置缺失和读取失败分别反馈。自有远端只使用真实远端接口，不能回退本机同 ID 的库、索引、Runtime 或凭据。未知写入失败继续原请求及宿主持久操作对账，原操作和删除清单的核对不会被库删除后的能力查询阻断。

## 文档界面

文档工具栏只保留搜索、筛选与库操作，不提供标题或重复计数，操作栏与表格之间保留分割线；文档计数统一由底部分页显示。库操作依次为设置、整理、上传资料；设置和整理仅显示图标，保留 Tooltip 与访问名称。详情不重复展示库标题和简介。表格将文件名称和文件大小分列展示，长文件名截断，完整名称可悬停查看。点击文件名打开共享 Dialog，展示基本信息、普通文档摘要与文件内容；不提供自定义元数据。Markdown 和文本读取原件字节，PDF、Office 等读取已保存的解析分块，不在预览请求中运行模型；尚未产生正文时保留原件下载入口。下载复用桌面保存能力。

文档列表由后端按文件名关键词、资料状态和上传时间顺序筛选后计数与分页，前端不再筛选或重排当前页。默认每页 10 条，可切换 30 或 50 条；搜索、筛选和排序变化回到第一页，实时状态减少匹配总数时回退到有效页。排队与整理中状态由同一读取事务中的活动任务和当前尝试投影，已完成来源的独立结论优先。自有远端使用同一查询合同；官方远端透传关键词、创建时间排序和其原生状态，不把本地专有整理状态冒充官方能力。

行尾菜单提供下载、重建知识与删除。本地重建复用模型配置和独立知识任务接纳；自有远端选择服务器执行配置，由远端执行。两条路径均传递显式 rebuild、所选来源版本与本次整理要求。普通整理继续跳过已完成来源；重建在接纳事务内核对来源当前头、授权、库版本及活跃写入，清理这些来源的分块、向量和旧摘要并重置为待处理。原件字节、已有 Wiki 与人工内容保持不变；同一请求回放不再次清理，接纳失败回滚。

删除先读取来源所有版本及 Wiki 影响，用户确认后才提交原预览摘要与稳定身份。沿用核心来源清理：人工和多来源正文保留并标记核查，单来源生成页面按预览归档清空。接纳回执不等于清理完成，界面核对持久清单并恢复原清单；未知结果关闭后重开继续原身份；来源行消失后通过持久清理清单入口继续，切换视图或重启不会丢失待完成清理。自有远端的上传、下载、实际持久分块预览、重建、来源清理与恢复使用连接范围接口；官方未开放的动作明确报不支持。

## Wiki 界面

Wiki 使用独立目录组件，目录行与工作区文件树复用 shared/ui 的展示组件，不调用聊天内部的文件系统行为。左侧支持索引、知识与摘要、搜索及树形／列表切换；知识按主题目录组织，摘要始终平铺，不重复展示主题目录。右侧读取所选页面的真实 Markdown。目录完整读取所有分页，正文独立按页面身份查询，切换不会保留其他页面正文。尚无持久索引时，索引入口只汇总真实页面元数据。

索引入口名称固定为“索引”，正文一级标题固定为“Wiki Index”；模型只更新概述，文档增删继续更新概述与目录。旧导言在生成与读取展示边界规范标题，读取不改写历史正文，普通 Wiki 页面标题不受影响。索引页沿 WeKnora 分离持久 Markdown 导言与动态分类目录。目录接口按全库轻量元数据分组分页，前端将分类层级、页面链接及摘要拼成 Markdown，通过共享渲染组件展示，不使用文件行样式。导言只渲染一次，不把原始 Markdown 当作摘要重复显示；新增文档不以本批候选替换全库目录。

Wiki 不提供重复库页头和计数栏。当前页面的编辑、历史版本和删除位于正文标题右侧，长标题截断且为操作保留空间；索引操作位于导言右侧。正文显示类型、版本标签及接口提供的更新时间，标题区与正文使用分隔线；Markdown 链接使用语义链接色和下划线。历史版本按需分页读取；本地页面通过既有归档写入从 Wiki 移除，保留历史版本，删除前明确确认。目录与正文隐藏滚动条并保留独立滚动。知识库与伙伴详情复用共享 Dock 导航和悬浮布局；业务层只提供导航项，玻璃表面、命中区、悬浮位置和正文避让均由共享组件负责。Wiki 页面容器使用 pane 布局，正文使用共享 Dock 滚动区；避让留白只在滚动内容内部，外层不生成底部占位栏。

历史弹窗独立列出当前版本，默认比较上一版到所选版的增量；历史版本还可查看到当前版的累计差异和完整原文。比较覆盖标题、说明和正文，使用与技能版本共用的按需差异组件；首版以空内容为基准。所选快照缺失时不能恢复，上一版未保留时明确提示并展示所选完整内容，不伪造版本范围；普通读取失败保留局部重试。上一版不在已加载列表时按真实版本补读，切换版本不沿用前一次正文。

本地及有实际写权限的自有远端可确认恢复历史版本，沿既有恢复接口追加新版本，保留历史、当前目录与排序，编辑来源记为版本恢复。恢复固定目标历史、当前页面版本、目录版本与请求身份；版本冲突不覆盖新内容，未知结果在页面生命周期内保留独立核对入口，关闭弹窗、切换库内视图或原历史行消失后仍重用原请求。成功后失效所属库及库列表缓存，正文与历史重新读取。官方 WeKnora 远端沿当前只读适配合同提供比较，其恢复写入仍明确拒绝。

Wiki 阅读器沿固定上游规则，仅在正文首个非空行是与页面标题同名的一级标题时省略该行，保留不同标题、代码块、后续章节和存储原文；图谱阅读器已有独立标题时复用同一规则。说明作为独立导言展示，主阅读器页尾按持久 `inLinks` 和 `sourceRefs` 展示引用当前页的页面与来源文档，不从正文另造引用事实。正文和引用区使用独立组件身份，切换页面不保留旧正文。

知识库卡片、文档列表、Wiki 目录及正文首次加载复用共享 Skeleton，按实际内容结构占位；代码分包与数据读取使用一致布局。后台刷新保留已有内容，错误就近提供重试，隐藏 Scene 暂停骨架动效。

页面与设置骨架只同步加载基础导航文案；配置扩展词典随编辑器加载，图谱完整词典随图谱视图加载。Dock 图谱入口不提前引入画布与图谱词典，保持现有页面和弹窗外壳即时挂载。

本地和具备实际写权限的自有远端支持新建根目录或子目录、新建页面；已有页面只编辑标题、说明和正文，保留目录、页面地址及类型。操作携带打开编辑器时的目录版本和页面版本，失败保留草稿，未知结果保留固定草稿、对象快照、版本和请求身份；关闭重开或切换库内视图后仍有独立核对入口，原行消失不会丢失入口。成功只失效所属知识库与库列表缓存。目录行的操作菜单在悬停、键盘焦点或展开时可用，提供新建子目录、重命名和删除。目录保持最多两层、同级名称唯一、仅空目录可删除的核心规则；服务端逐次校验权限与结构版本。远端目录逐级完整读取，返回前校验自有完整目录表，缺失父级、重复身份、环与中断不能被视为成功的空目录。页面选择进入 URL，知识事件复用原资源订阅，隐藏视图不启动专属读取。Markdown 内部链接在库内定位，外链通过桌面适配打开；不执行原始 HTML，也不自动加载远端图片。

## Wiki AI 修订

当前页的 AI 修订复用共享 `ChatPane`、右侧工作台全屏时使用的 `FloatingChat` 与普通 Chat／Execution，按需加载维护视图，不另建聊天渲染器或内容状态机。首次发送固定后端、连接、库、页面及已读版本；后续发送保留同一绑定。关闭浮窗、切换文档／Wiki／图谱或切换知识库时保留原会话身份，隐藏 Scene 退出浮窗展示。页面修改成功后复用所属资源事件失效，正文与历史从核心重新读取。

本地维护入口以个人助理执行用户要求，服务端只签发原库读取和当前页修改工具，工作区只读且不装配额外 MCP。持久绑定复用宿主操作引用；不能通过普通聊天历史入口续发或原生重试解除范围，继续修订须回到原页面维护入口。首发和续发复用已有请求身份及消息接纳回执；结果未知时保留原消息与配置核对，不生成新身份重复发送。

修复流程迁自固定 WeKnora 的 `wiki_fixer`：读取当前页与用户修改要求、回读真实来源、确认问题仍存在、做必要的最小修改并回读核对。维护工具迁入整页写入、精确文本替换、重命名和归档，沿核心 SQLite 事务保存正文、版本、链接、活动与回执。AI 修改记为 Agent 来源；整页写入保留人工保护，明确替换只调整匹配的保护文本，不静默解除其他保护。重命名保留稳定页面身份并更新真实入链；归档清理入链但保留历史，代码示例不当作真实链接重写。

页面只提供 AI 修订入口，用户在聊天中直接描述修改要求，不提供全库问题、当前页问题或手动标记问题的界面。手动问题管理的接口、CLI 命令与绑定一并移除；整理管线的自动质量核查继续保留。页面 AI 修订目前只支持本地；自有远端维护工具使用真实代理接口，尚无远端聊天接纳合同。官方远端未开放的维护写入明确拒绝。

## 图谱界面

图谱展示 Wiki 页面之间的真实链接，不启动额外实体抽取。画布直接填充详情内容区，不保留库页头或资源页内边距。布局算法与回归测试直接迁自固定 WeKnora；呈现参考其 WikiBrowser 的 SVG 画布、逐帧力导向、连通分组轮廓、下置标签、主题名称和悬停关联高亮。搜索与类型图例悬浮在画布上，类型可独立开关；节点支持拖动固定，画布默认支持空白拖动、滚轮缩放与箭头开关。背景和左下缩放控件与工作流共用，不提供移动模式按钮或无链接页面开关。悬浮控件之间的透明区域不拦截画布事件。代码按视图分包，不增加图谱依赖。

画布沿用本地 WeKnora 的命令式 SVG 渲染机制。React 仅维护容器、共享控件与可见状态，节点和边在图数据变化时创建；布局和视口动画直接更新既有元素属性，不触发整图 React 重渲染。标签避让与分组轮廓每六个布局帧刷新，轮廓只在缩放或实际坐标变化时重算；文本宽度在全部 SVG 写入完成后集中测量。拖动只更新当前节点和相连边，增量展开保留已有位置、固定状态与视口。宿主适配负责零尺寸等待、Scene 和窗口隐藏时暂停，以及卸载时释放帧、监听器和定时器。

单击节点在右侧按需读取真实 Wiki Markdown，正文内部链接在图中定位。双击或展开邻居聚焦一层邻域；Shift 单击、节点悬浮加号和扩张边缘叠加邻域，保留已有位置与固定节点。远端按最多六个并发请求读取邻域，合并上限为 1500 个节点，淘汰旧扩张时保护初始节点、当前中心及选择。

本地与自有远端图谱复用各自 Wiki 的完整分页查询与持久链接投影，不使用文档列表或 Wiki 当前分页合成全库关系。概览与单次邻域最多显示 500 个节点，累积展开最多保留 1500 个节点，从完整关系中按连接度选择；搜索可定位概览之外的页面。官方远端使用原有有界图谱接口与全库页面搜索，保留实际覆盖范围与截断说明。节点关联数保留原始关系事实。服务器数据仍由 TanStack Query 管理，并复用所属库的事件失效；隐藏视图不启动额外读取，动画在隐藏或卸载时释放，减少动态效果模式直接呈现收敛结果。

## 数据权威与配置

本地知识库使用独立 SQLite 和受管原件目录。上传入口提供文件、文件夹两种来源，支持 Markdown、文本 PDF 和 DOCX，当前不支持网页链接。文件夹选择递归读取其中的支持格式，过滤路径中以点开头的隐藏文件和目录；相对路径仅用于队列中辨认文件，核心接收的文件名不包含目录。上传保存原始字节，不自动整理。上传弹窗外壳随知识库页面加载，内部表单按需加载；加载与表单就绪共用同一个弹窗实例。本地仅创建通用库，不提供类型选择或项目知识库入口。

核心只初始化空库的当前 schema 或校验现有结构，不保留历史开发 schema 的迁移框架。数据库清空属于独立离线操作，不在应用启动时自动丢弃内容；受管原件根仍核对数据库路径、目录身份与既有归属。

Wiki 正文、稳定页面身份、版本、来源证据、分块、向量、模型调用诊断和整理检查点由核心数据库保存。库配置包含 WeKnora 整理偏好、索引策略和分块配置。整理弹窗完整分页读取全库来源，通过共享可搜索多选控件默认选中待整理、失败及已取消的文件，用户可调整范围；当前列表页、搜索筛选和表格勾选不限定默认范围。单次整理可填写提取要求，与知识库长期整理偏好一同生效，随知识任务冻结，不回写库配置。整理接纳时冻结配置与来源版本，运行中的配置变化不改写该任务；未知结果重试保留原文件集合、单次要求和请求身份。

分块直接迁入固定版本 WeKnora 的算法与回归测试，包含自适应策略、Markdown、父子块、语义边界与来源位置处理。配置字段保留上游含义；解析引擎规则和表格元数据指令在当前适配未支持时明确拒绝，不能保存后静默忽略。创建表单预设与算法的默认归一规则分别沿用上游，包括重叠值为零时的归一行为。

模型选择复用共享 Runtime、账号和模型控件，按知识库存为宿主默认配置；设置与整理入口读取同一记录。接纳时将选择冻结到独立任务配置，后续修改默认配置不改变已接纳任务。整理不显示聊天权限或推理强度选择，默认遵循上游关闭 thinking；适配器记录模型实际支持的配置。

新建与编辑使用同一编辑器、字段模型和校验。新建时选择本地或已启用远端连接，目标进入同一草稿；远端创建按连接级创建授权处理，不能从已有库的写权限推断可创建。远端请求不携带本机执行默认值或 Embedding 密钥。本地配置包含基础信息、模型配置与分块设置，自有远端编辑实际核心配置及活动；尚无远端合同的宿主模型配置明确提示不支持；编辑另有只读活动记录。弹窗外壳跨代码加载、数据加载和编辑保持同一实例，只有内部内容切换，避免重建弹窗与重复播放动效。知识库 ID 使用只读信息表面；必填字段复用统一标记，启用 RAG 向量索引时必须完成本库 Embedding 配置。

界面不提供 Wiki 编写语言选择；分块识别的语言提示位于高级选项折叠区，留空表示自动检测。分块配置直接编辑策略、大小、分隔符和高级识别参数；索引策略使用底色与勾选状态表达选择。

核心配置与宿主执行默认配置分属两个数据库，保存依靠稳定请求身份、版本比较和独立持久回执恢复部分完成状态，不承诺跨库事务。 宿主只登记连接、独立任务配置、库模型与 Embedding 偏好以及实际回执引用，不维护项目或软件库关联表。创建中断后重试补齐原库，不能重复创建。

索引策略以 RAG、Wiki 两个选项表达。RAG 统一控制向量与关键词索引，至少开启一种管线；新建默认 Wiki-only。已有内容时编辑界面锁定策略，分块配置按原保存值回填。关闭 Wiki 时只执行原件读取、真实分块索引、上游普通文档摘要及最终核查，摘要与 Profile 保存到来源元数据，不生成 Wiki 页面、主题或索引简介。该路径仍须取得对应生成调用的真实成功终态并通过发布授权检查，不能以完成向量写入冒充整次整理成功。

Embedding 地址、模型和加密密钥按知识库独立保存，与记忆配置及其他知识库互不影响。模型配置直接内嵌服务表单与连接测试，空密钥保留本库已有值，读取不回显密钥。只复用通用嵌入客户端，不读取记忆设置，也不将记忆凭据复制为知识库默认值。尚无独立配置时明确要求配置，不能静默回退。

整理与检索按同库配置冻结模型和服务地址指纹，检查批次顺序、数量、维度及有限数值后保存向量。分块失败或嵌入失败均保留真实失败状态，不把候选、关键词搜索或待处理状态表示为向量就绪。普通知识搜索在首屏附带最多五条原件命中；启用向量时真实嵌入查询并校验向量空间，返回子块定位及同版本父块上下文，读取父块使用有界身份查询。远端读取不访问本机索引，嵌入失败不静默降级。

Markdown 直接读取；文本 PDF、DOCX 使用受限文本提取。OCR 与复杂图表不属于当前阅读能力。Wiki 引用使用实际分块结果，不另建一套近似分块。

## 活动记录

活动类型、结果、游标和筛选语义迁自固定版本 WeKnora。核心保存独立审计记录，内容变更与对应活动在同一 SQLite 事务中提交；宿主执行默认配置另以稳定请求补记到同一活动流。重放不会重复记活动，也不从任务列表拼接历史记录。

活动只保存对象身份和必要安全摘要，不保存原文、提示词、候选正文或凭据。人工操作使用实际本机用户身份，后台整理沿用任务冻结的发起人。前端按时间、操作、对象、发起人和结果展示，支持操作与结果筛选、刷新和游标分页。

## 聊天整理

聊天通过用户自然语言请求发起整理，输入区不提供知识库专用按钮或目标选择状态。系统 `ally` skill 识别知识查询、附件入库及整理意图，按需读取知识参考。智能体先通过 `knowledge.libraries.list` 查询目标；只有用户明确指定或已回答确认、且能在当前列表唯一匹配的知识库才可触发整理。用户未说明目标、查不到或存在重名时，必须使用已有结构化问答并等待回答，确认后重新核实目标。即使当前仅有一个知识库，也不能替用户选择。

普通执行额外签发 `knowledge.jobs.start`，目标只能来自本轮冻结的本地通用库集合，每次调用重新核对知识库策略、伙伴、项目和实际执行身份。附件参数是触发本轮执行的用户消息中从零开始的序号，服务端只导入相应受管附件，不接受任意文件路径。显式选择附件时不捎带库中其他待整理来源；仅在用户要求整理库内待处理资料时省略来源选择。单次要求随任务保存，后台以独立任务配置选择 Runtime、账号和模型，不继承聊天的推理与工具权限。

整理通过独立模型任务接纳与库拥有的后台任务执行。请求身份绑定聊天和执行，持久输入摘要拒绝同键更换目标或附件；重复请求及未知结果通过原核心回执核对。普通聊天只报告已接纳或无需处理，不接管后台管线，也不把接纳当作发布。远端整理不能回退本机，未提供相应 CLI 能力时明确报告边界；知识库页面原有上传与手动整理入口继续使用各自真实接口。

## Lite 管线与模型接口

整理引擎以固定 WeKnora Lite 源码为依据：每批最多五份待办，同库串行处理批次；批内 Map 和 Reduce 分别最多十路，单文档引用批次最多四路。流程包括真实阅读与分块、知识抽取及其上游回退、文档内去重、摘要与引用、统一目录规划、按页面合成和局部发布，最后处理索引导言与链接。业务解析、来源更新和失败重试归核心所有，CLI 只返回模型正文。

模型边界为同步 `Generator.Generate`，显式传入角色消息、生成参数与阶段身份，返回正文、原生停止原因、用量及实际能力诊断。普通调用拥有独立上下文；长度续写仅使用本次调用的消息。阶段输入、结果及失败保存为知识任务诊断，既不创建聊天会话记录，也不经过候选文件交接和智能体命令调度。

本机 API 只返回知识任务接纳回执和冻结模型配置。界面核对原请求、知识库和任务身份后关闭弹窗；缺失或不匹配的回执按结果未知处理，沿原请求核对，不换身份重复接纳。文档列表显示来源权威状态，失败原因通过状态标签的悬停或键盘焦点提示查看。文档详情只展示基本信息、摘要与原文，不重复整理状态；没有整理过程或聊天查看入口。

用户界面与宿主公开操作不提供停止整理。服务关闭和资料删除仍通过内部取消与发布屏障阻止迟到响应，不能因此把已接纳任务或部分成果标记为完成。

上游 Map、摘要、页面持久写入等失败按各自语义局部处理；引用批次失败保留其他批次，Reduce 生成失败保留旧页或不创建新页。成功页面及时提交，失败来源不能回滚无关成果。知识存储仍核对当前授权、取消屏障、来源版本和目标页版本，来源撤回与重解析沿原贡献关系处理。索引和链接收尾失败不回滚已发布页面。

## CLI 调用与生命周期

知识 CLI 复用唯一 `agentcapability/contract`、既有资源读取提供者和真实核心操作。能力覆盖库详情、来源列表和持久正文分块、页面与目录、索引、历史版本、任务、核查、活动及导出；修改覆盖 Agent 页面修订、精确替换、重命名、归档、历史恢复、目录、原件导入和任务重试。完整命令清单与使用方式见 [allycli README](../../server/cmd/allycli/README.md)，参数以当前执行的 `capabilities` 和 `describe` 为准。

来源正文读取使用已保存分块，按来源版本、块身份和位置分页，有界截断明确返回，不触发重解析或模型。写入冻结可见通用库、连接版本、库策略与活跃执行，每次调用重新授权；修改必须携带相应页面或目录版本。未知远端写入只查询原请求回执，核对操作与目标身份后才确认完成；明确拒绝持久保存并按原错误重放，不被转为未知。任务接纳与完成分开，CLI 通过任务读取观察真实终态。没有实际远端协议的操作明确不支持，不读取本机同 ID 内容。

`Runtime.GenerateText` 复用 ACP 的程序、账号、模型选择与取消能力，每次创建独立原生上下文，使用临时空目录，调用结束后释放会话、进程与目录。不装配伙伴档案、宿主系统技能、额外目录或问答 MCP，不使用聊天事件日志。

知识模型采用 `isolated_text_generation` 三态能力：真实 ACP 临时会话完成模型目录读取并成功配置隔离模式后为支持；隔离模式不支持或配置被拒绝时为不支持；旧缓存、未完成会话探测或账号未登录时为未知。未知不等同于支持，允许进入任务后先通过实际账号的新会话配置验证，失败时不发送生成请求。宿主和 Runtime 拒绝明确不支持的配置；知识表单过滤这些智能体，对未知显示生成前验证及刷新探测说明。默认受管账号沿 Runtime 现有私有账号探测链路处理，不要求系统账号登录。能力表示当前隔离生成策略可配置，不表示全部原生工具已关闭，普通聊天继续使用原有能力规则。

Codex独立文本调用使用临时HOME、CODEX_HOME和XDG目录，仅复制认证与provider连接配置，不继承全局AGENTS、skills、hooks或MCP；模型目录中的内置代码助手指令也被清除。原system正文通过官方model_instructions_file替换基础指令，原user正文直接发送。只有user的调用使用明确诊断的中性基础指令“Respond to the user request.”，满足原生CLI非空约束，不改Lite业务模板。关闭project_doc_max_bytes、skills.bundled.enabled与skills.include_instructions对应的读取或注入。原生Responses当前以developer消息承载基础指令，不伪称供应方原生system角色。配置依据见[官方配置定义](https://github.com/openai/codex/blob/main/codex-rs/core/config.schema.json)与[配置参考](https://developers.openai.com/codex/config-reference)。

认证种子仅接受有界普通文件并以0600写入临时目录。OAuth在读取实际认证种子前取得同进程同路径租约，覆盖完整原生调用与刷新回写，等待可取消；API Key调用保留并行。刷新只在原认证内容未变且账号身份一致时回写，不承诺跨进程CAS。仅keyring认证无法迁入临时主目录时明确失败，不整树复制用户配置。调用成功、失败、取消后均清理临时目录；普通Chat与原账号目录保持原生命周期。

受管订阅账号的知识调用等待既有账号租约，等待可取消，并在上一调用回收认证后投射本次配置；API key 共享规则不变。该等待只接入知识模型生成，普通聊天继续使用原准入规则。管线并发上限不等同于同一订阅凭据可以并发刷新。

Claude 使用已支持的原生参数关闭工具；Codex仍保留原生权限/会话元数据及部分工具定义，assistant续写历史仍以文本表达，均在诊断中记录。其他Runtime沿现有账号行为，将角色与顺序编码到单一用户文本，系统账号可能加载自身全局配置。任何观察到的工具、审批或问答请求都会取消生成并丢弃部分正文。这些平台不具有相同的原生消息合同，不能称为与 HTTP Chat API 完全等价，也不能将宿主没有聊天日志等同于所有CLI没有原生日志。

上游默认 `Thinking=false`。实际模型声明 `none/off/disabled` 且配置回执确认时才记录为关闭；只能使用较低推理或不能配置时记录真实值和限制。当前 ACP 无法设置的温度与输出 token 上限也明确记录，不能把请求参数当作已经生效的参数。

知识 Service 持有作业 Context 与后台生命周期。服务关闭取消直接模型调用并保留可恢复任务；资料删除先保存不可发布屏障，迟到响应不能继续发布。重启沿持久任务、来源待办和调用结果恢复。已接纳任务必须具有同一次接纳冻结的模型配置，缺失时明确报告错误，不忽略损坏引用。整理没有额外的整批总时间预算。

原件目录与数据库绑定身份，永久删除及磁盘清理由核心持久状态约束。删除库清理知识资源与宿主引用，不调用聊天删除流程；普通用户聊天与其他知识库不受影响。

## 独立核心交付

核心在独立仓库开发，NeuxAlly 固定快照位于 `third_party/neux-knowledge`。只通过生成器更新：

```sh
node scripts/sync-knowledge-core.mjs /path/to/neux-knowledge
node scripts/sync-knowledge-core.mjs --check
```

生成器记录逐文件与整体摘要，快照不手工修改。Go 相对模块替换允许干净检出引用固定源码，构建不依赖个人目录。

WeKnora 是实际代码基础。固定提交、原文件摘要、迁入路径与必要适配保存在核心 `upstream` 清单；第三方版权和许可见 [第三方说明](../../THIRD_PARTY_NOTICES.md)。宿主保留 SQLite 存储、授权和 CLI 执行适配，不替换上游算法与提示词语义。

实现入口为 `server/services/knowledge`、`server/internal/knowledge` 和 `server/apis/knowledge`；普通聊天的知识能力指引在 `skills/ally/references/knowledge.md`。需求范围见 [知识库规格](../discussions/knowledge-base-specs-cn.md)，实际检查结果与尚未验证的边界见 [验收记录](../discussions/knowledge-base-acceptance-cn.md)。

## 验证边界

上游算法回归、SQLite 与模拟执行测试、HTTP 合同、真实模型整理和界面验收分别提供证据。Wiki 未确认命令的草稿保留在当前页面生命周期内，不承诺应用重启后的草稿恢复；整库删除按已知原请求和持久清单核对，当前没有跨重启发现所有已删库的任务中心。来源清理已有独立持久入口，继续沿该入口恢复。静态与自动化检查不能证明真实 CLI、账号、模型生成质量或视觉效果，也不能证明任意版本的官方远端服务器兼容。
