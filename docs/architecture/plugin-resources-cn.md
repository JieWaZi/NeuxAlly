# 插件资源

## 事实与归属

资源库聚合插件、独立技能和独立连接器。插件资源保存稳定身份与归属；版本保存不可变内容、摘要、原始清单及来源；伙伴安装保存明确版本和启停；共享设置保存唯一修订及加密密钥。伙伴之间不复制账号或配置。

全局资源可先保存在本机，再明确安装到伙伴；伙伴自行导入的资源归该伙伴所有。全局发现与实际安装分别查询。展示名称可以重复，运行时技能身份使用 SKILL.md 的声明名称；同名同内容只投射一份，不同内容拒绝接纳。

包内技能和 MCP 是版本派生组件，不登记为独立安装资源，也没有独立编辑或升级入口。当前模块按新数据库建立目标结构，不包含历史转换或迁移路径。

## 来源与交付

正式解析器位于 `server/internal/plugins`，依次识别根 `plugin.json` 的 Agent Plugins 1.0.0 清单、`.codex-plugin/plugin.json` 和 `.claude-plugin/plugin.json`。兼容导入保留完整包、原作者、许可和上游版本，归一化可交付的技能以及 STDIO、HTTP、SSE MCP；默认技能与声明的附加目录或单技能目录合并，相同规范化路径只保留一个组件。默认 `.mcp.json` 与显式 JSON 文件、内联服务对象及其混合数组按声明顺序合并，同名服务采用最后一项有效声明。原生 hooks、agents、commands、LSP、托管 apps 等完整保留，并单独返回原生组件索引。当前目标有明确原生引用时优先选择同一固定来源中的原生实现；没有引用时使用自有内容。Codex 与 Claude 原生会话可交付完整包；其他目标只投射已支持的 Skill/MCP，诊断中列明不投射的原生组成。纯引用缺少目标实现时准确失败，显式引用解析失败不回退。格式依据 [Codex 插件规范](https://developers.openai.com/plugins/build/plugins) 与 [Claude Code 插件规范](https://code.claude.com/docs/en/plugins-reference)，不推测外部账号或托管连接映射。通用格式的标准保留变量只在 args、env 与 cwd 中替换；兼容格式还解析命令、地址及请求头中的配置变量，交付前复验最终远程地址与请求头。客户端配置绑定位于 `com.ally`，不改写标准字段语义。

展示资料由各格式的 `interface`、公开清单字段及本机表现扩展归一化，作者身份仍保留原始声明。包内 PNG、JPEG、GIF 和静态 SVG 可作为软件图标，读取限制为 256 KiB；SVG 拒绝脚本、事件、样式、外部引用与 `foreignObject`，无效图标使用默认图形。根 README 的内置阅读限制独立为 1 MiB 的 UTF-8 Markdown，提供 available、empty、missing、too-large、invalid 状态；超限完整快照保留，可经固定来源原文接口下载。预览按渲染高度裁切，完整弹窗复用静态 Markdown，不截断源码。列表只返回正文状态，完整正文在详情按版本读取。技能正文仅通过已发现组件键读取；已安装版本先复验完整摘要，目录预览先验证归档，临时快照读取后释放。

插件详情中的技能弹窗展示固定版本的元数据与 Markdown 说明正文，名称、数据源和描述复用技能详情页的阅读组件；资源列表中的插件技能进入独立只读详情页，显示元数据与正文，不提供资源文件、历史页签及编辑、更新或删除入口，URL 保留插件版本与组件键。独立技能页继续提供元数据、资源文件与历史。技能读取接口保留实际资源清单与版本快照。资源路径相对该技能目录，清单保留目录、字节数、内容摘要和执行位；只在选择文件时读取正文，预览上限为 1 MiB，二进制使用 Base64 表达。读取拒绝清单外路径、目录和符号链接；声明为插件根目录的技能还会排除插件清单、共享配置与其他组件。已保存插件的历史只包含同一组件键实际保留的插件版本，查看历史时重新核对相应不可变内容；目录技能只显示当前声明版本，不伪造本地历史。

本地目录和 ZIP 先完整复制到受管暂存区，预检令牌绑定摘要；摘要使用带长度的路径记录和逐文件摘要，内容不能伪造另一条文件边界。准备时复验相同快照，再写入按完整摘要寻址的内容目录。清单中的 repository 只是作者声明；未核验本地来源使用内容身份，只有明确选择已有插件才更新其版本。随包目录使用经过构建校验的独立目录项身份。

默认软件目录来自 [独立插件仓库的 HTTP Release 清单](https://github.com/JieWaZi/NeuAally-Plugins/releases/latest/download/catalog.json)。目录检索只读取有界元数据；清单缓存五分钟，来源不可用时保留旧缓存并显示 stale、时间及稳定错误。首次同步失败不伪装成零条目。`ALLY_PLUGIN_CATALOG_URL` 可明确指定 HTTP 镜像或本地目录；旧应用资源目录不覆盖默认在线来源。安装按同一目录项的 sourceCommit、archiveURL、archiveSHA256 和 packagePath 下载并校验 ZIP，半包或摘要错误不发布。运行期间没有 Git 可执行文件依赖，应用构建不携带插件安装 ZIP。

ZIP 解开后保存完整来源根，逻辑入口和 `.neuxally/integration.json` 引用的 Codex/Claude 目录处于同一不可变快照。引用始终相对来源根解析，路径穿越被拒绝；单包导入不得访问包外内容。入口版本与每个原生目标的实际名称、版本、摘要及组成分别保留。

独立仓库的官方收录只维护上游地址、固定提交、包路径及完整性锁，发布构建通过 HTTP 取得完整包并物化进 ZIP。应用消费完整发布产物，不把仅含来源声明的源码目录当成可直接执行的插件。原生目标配置从实际清单推导并合并供系统编辑；其他目标字段不变为全局必填，执行只校验并交付当前目标所需的配置。供应商凭据沿受保护配置保存，不进入公共结果。

飞书办公保留固定官方提交的完整技能目录、相对依赖、许可和 provenance。文档、多维表格、日程和任务是首版主要业务验收路径；第三方作者与包装维护者分别记录于 [第三方声明](../../THIRD_PARTY_NOTICES.md)。

## 安装与卸载

未安装插件点击条目直接进入详情页。点击安装后展示 NeuxAlly 与插件图标，先选择一个或多个伙伴，再处理必要配置与共享认证。当前会话明确返回二维码、外链或验证码动作时，安装面板显示对应交互；普通 URL 不自动生成二维码。授权信息使用简短的提醒区域说明账号共享范围，认证完成后为所选伙伴安装。准备、授权和数据库安装关系分别处理；取消选择不会产生占位关系，也不会清除已完成的共享认证。批量安装逐伙伴返回结果，重复安装保留原版本与启停。

普通设置更新验证所有保留安装使用的版本。内容继续按完整摘要保存不可变版本，准备不会改变伙伴安装，相同版本号不能覆盖不同内容。当前开发阶段不提供用户可见的插件检查更新或版本切换流程；第三方插件显示官方来源版本，自有插件使用自身版本。官方远程服务显示“官方托管”，不将内部包装版本当作远端部署版本。

伙伴卸载全局资源保留其他伙伴关系；整体删除先确认实际影响集合。卸载最后一个使用同一提供者的实际安装时，先取消未完成授权、等待官方进程退出并清理本机共享授权，再删除关系；删除没有安装的资源也会检查同一提供者是否仍被其他伙伴使用，避免保留孤立授权。关闭的安装仍属于保留引用。清理期间阻止新安装和新执行取得身份，已有工作占用会阻止最后引用删除；其他伙伴仍有安装时不清理共享账号。官方清理在数据库事务外执行，清理失败保留原关系供重试，准备或首次安装不自动清除已经完成的授权。内容与 PLUGIN_DATA 在数据库引用和活跃执行占用均消失后回收。准备、接纳与回收由同一进程内内容边界协调，回收不穿过受管子目录链接。

## 执行与连续对话

Execution 在接纳时读取同一事务中的资源、版本、安装和配置，复验内容摘要，再按探测到的目标选择完整原生包或 Skill/MCP 投射。Codex 使用应用私有 CODEX_HOME 的固定缓存及工作区 marketplace；账号配置只沿白名单复制，不修改原账号和用户全局插件配置。Claude 使用本轮 `--plugin-dir` 参数。跨格式派生转换有明确映射的身份、技能及 MCP，完整保留源文件及原生组件声明并交目标原生机制解释；无法证明事件等价时保留诊断，不声称跨端语义兼容。同一组件只交付一次；带连接器或软件能力白名单的受限入口不交付原生整包，包含 CLI 身份环境的技能桥接同样拒绝进入受限入口。

原生快照变化时后续普通会话重建并复用既有有界历史；不把旧线程句柄传给新的私有配置根。已分支会话不能重新注入继承历史时准确拒绝。相同快照复用私有配置目录和完整缓存，缓存被篡改时拒绝，不原地改写其他活跃执行正在读取的包。原生 CLI 自身的用户级默认技能发现与受管插件身份分别存在，私有 CODEX_HOME 本身不宣称隔离所有用户级技能。

自动按需能力来自伙伴实际启用安装；本轮明确引用通过 pluginIds 单独提交，并只附加本轮选择提示。`allycli capabilities` 公开本轮真实授权的插件目录、详情、安装和状态操作，伙伴与 Execution 从服务端绑定。CLI 与 HTTP 安装复用 `services/plugininstallation`，同一请求身份的回执与安装关系在同一数据库事务提交；重复调用保留版本及启停。安装回执表示系统伙伴关系，不表示当前执行已加载；新能力从下一次执行开始生效。

STDIO 配置经过 Core 的无协议转换启动模式设置 cwd，保持原始 argv、env 与三个标准流；没有 shell 字符串拼接。MCP 传输依当前智能体探测能力交付，派生服务使用稳定组件授权身份并继续接受现有 MCP 白名单限制。受限入口不会自动取得飞书 CLI 技能和共享 profile 环境；GitHub 仅交付白名单允许的官方 MCP；MCP 白名单本身不构成 shell 沙箱。

消息保存明确选择的插件展示快照，执行保存实际交付插件的版本、配置修订、提供者身份及组件身份，不保存凭据。重试必须满足原版本、配置修订、身份、组件集合、实际目标摘要与交付方式，无法恢复时明确失败。原生会话挂载和进程环境继续由 Runtime SDK 管理，提供者身份变化参与环境指纹。

## 共享认证

`internal/plugins/authorization` 统一管理会话、Core 生命周期、取消、工作占用和安全摘要。v2 只在 `.neuxally/integration.json` 声明 `plugin-command` 与 `neuxally-auth/1`，宿主用固定包内入口及独立 argv 启动，供应商 CLI 和扫码解析归包内桥接。宿主只理解 auth/start、status、cancel、resolve、logout 的逐行 JSON-RPC 和绑定当前会话的 challenge/state 通知；URL、二维码、验证码按本次 actions 渲染，不按插件名称判断。deadlineAt 与官方 expiresAt 分别表达本机等待和上游期限，取消等待真实进程退出，终态清除临时挑战。

桥接 resolve 只接受本轮获准的稳定组件身份，秘密绑定不进入 HTTP 公共结果、聊天、日志或索引，不能修改已核准端点或 Runtime 身份。PATH 只能由插件私有已核验目录和宿主原有受信路径组成。不同插件按资源身份隔离私有数据与账号；同一插件所有伙伴共用身份租约。桥接指纹包含完整内容摘要及实际包路径，版本只能在无授权等待和执行占用时更换；旧桥接与新桥接不能同时绕过同一共享身份边界。旧版飞书/GitHub 专用适配继续服务已保存 v1 资源，不能作为 v2 新插件接入的供应商分支模板。

包内授权程序、MCP 和其他原生执行组件均纳入受管预检的执行确认，扫描结果返回权威 `trustRequired`。未确认版本不能启动授权桥接，包括直接授权接口。桥接取消先发协议请求并给上游停止窗口，随后回收受管进程组及关闭读取，避免子进程持有 stdout 造成永久等待。

### 既有 v1 资源的供应商适配

固定官方程序通过显式 PATH 进入受管智能体子进程，配置通过 LARKSUITE_CLI_CONFIG_DIR 指向应用私有 provider 目录。授权进程与执行目标均清除继承的官方 CLI 身份、profile、代理及数据目录覆盖，防止外部环境替换共享身份。应用不安装全局程序，不读取其他 CLI profile，也不复制用户 token。

首次连接通过固定官方 CLI 的 `config init --new` 扫码创建应用，凭据由 CLI 直接写入私有 profile；随后继续最小权限用户设备授权。界面不提供 App ID / Secret 输入，原有 profile 直接进入用户授权。两阶段复用同一会话和身份占用，原始二维码链接只在等待期间可见；首次应用扫码显示本机十分钟等待上限，实际期限仍由官方进程负责。Core 拥有唯一授权等待、期限与取消，取消后仍保持身份互斥直至设备进程实际退出，并在关闭时等待子进程结束。飞书在伙伴选择后直接展示二维码，GitHub 展示设备验证码及“打开授权页面”入口；等待结束后清理原始链接和验证码，通过统一资源事件恢复状态，没有页面永久轮询。

安装弹窗仅由统一资源订阅刷新详情，读取成功后按原伙伴选择自动继续安装；认证面板只在权威会话就绪且账号可用时通知完成。全部安装或重新授权成功后刷新列表并自动关闭，不要求再次点击添加或完成；部分失败保留重试入口。二维码等待期间始终提供刷新入口，刷新先取消并等待旧进程退出，再发起新会话。界面在当前设备期限仅设置一次定时唤醒，隐藏旧二维码并读取一次权威状态；新二维码更换期限后重建计时，结束或卸载时释放，不增加认证轮询。首次应用设置未暴露官方有效期时，仍只按本机等待上限展示。

界面按插件声明请求最小权限，重新授权时携带服务端确认的缺失权限，不要求用户填写权限标识。账号区域显示连接状态及官方授权入口，已连接且权限完整时不重复展示连接操作。通过资源库发起的首次配置、退出和身份更换，与使用该身份的活跃执行互斥；占用状态提供关联工作的链接。业务执行收到稳定说明：身份和配置变更回到资源库处理。该协调不宣称隔离同一系统用户自行启动的外部程序；外部撤销和资源权限错误仍可能影响进行中的调用。

GitHub 使用固定 GitHub CLI 2.102.0 源码隔离构建（2.102.0-neuxally.1）的非交互设备流程，不要求用户创建 OAuth 应用。应用私有 `GH_CONFIG_DIR` 使用官方文件凭据，目录 0700、凭据文件 0600；`--insecure-storage` 配合底层 Set/Get/Delete 的 neuxally: 命名空间补丁，避免官方隐式调用及迁移触及机器已有 gh 钥匙串；Core 在任何认证命令前校验隔离构建版本。授权进程清除继承的 GH/GITHUB 覆盖；GitHub profile 与 CLI 目录不交给智能体。退出只移除本应用 profile，不表示撤销服务器授权。

GitHub 权限满足遵循官方包含关系，统一供完成确认、状态、安装、API 缺失权限和执行使用。自动跳过未就绪或无可交付组件的插件时，未被其他实际组件使用的提供者租约在接纳前释放。

GitHub 验证码与原始设备 URL 分开显示，可复制验证码，在手机或网页输入。CLI 不返回官方到期时间，显示 Core 本机 15 分钟等待上限；CLI 自己处理官方设备轮询，前端只消费统一状态事件。

GitHub 插件直接提供官方远程 MCP，CLI 仅由 Core 用于共享认证。实际执行在同一身份占用内验证账号、读取私有 CLI token，将 Bearer 仅注入精确 `https://api.githubcopilot.com/mcp/` 的 streamable HTTP 连接器；其他域、路径、查询或 STDIO 被拒绝。工具组固定为 context、repos、issues、pull_requests、users，清除包内可能覆盖认证和 MCP 选项的请求头。凭据不进入消息、模型指令、共享设置或快照。远程服务由 GitHub 持续部署，不声称实现版本被本地来源锁固定。

## 接口与前端

插件接口在 `server/apis/plugins`，独立技能与连接器通过各自全局 LibraryRouter 和伙伴操作复用同一用例。完整 HTTP 契约由 [OpenAPI](../../server/openapi.json) 生成前端 Client；不手工维护第二份协议声明。

资源库以三个可键盘切换的分类入口组织插件、技能和连接器，下方共用紧凑图标条目和按内容容器降列的三列网格。插件提供文字加底部指示线的“插件库 / 我的插件”切换，后接当前结果的资源数量，以及本地目录或 ZIP 导入；插件库保持图标、标题、单行简介与“+”入口。只有当前存在实际安装且共享身份明确不可用时才显示“授权”；任一伙伴完成共享授权后恢复“+”，不根据提供者类别直接判定需要授权。安装与授权成功使用绿色状态提示，与授权中的黄色说明复用同一提示容器。安装弹窗先关联目录对应的真实本机资源，再读取详情接口；伙伴选择器展示真实静态头像，已安装关系勾选并禁用。重新授权复用已有安装，不重复安装伙伴。我的插件复用普通资源 Card，底栏提供实际伙伴使用数和更多操作菜单，不增加分隔线，不重复展示已授权、开发者与版本。添加或导入操作统一位于标题右侧并使用页面主操作，伙伴资源页不重复提供列表内安装按钮。技能与连接器支持“全部来源、来自插件、独立安装”筛选，默认按独立安装、来自插件的顺序各预览最多九项；分组有数据时才显示完整计数与筛选箭头，筛选后不重复显示来源标题。插件列表与筛选后的卡片列表首批显示九项，后续按滚动追加，不提供翻页控件。插件、技能与连接器列表保留数量、选择与批量删除入口，技能与连接器保留分类标题；插件删除确认以图标、名称和伙伴使用数列出目标，并说明共享配置、伙伴安装关系和不再使用的本机授权信息的清理范围。内置资源和包内能力不作为独立删除目标；包内能力通过所属插件管理。包内能力直接读取插件快照，伙伴页只展示其实际安装版本，关闭或未就绪的插件能力仍可查看，启停和配置由所属插件统一管理；预检显示来源格式、开发者、版本、许可、组成和兼容性诊断，含 MCP、原生执行组件或授权程序的包按预检结果确认执行内容。URL 保存分类、视图、搜索与来源筛选。目录插件和已保存插件均使用详情页展示简介、可点击查看正文的技能、连接器、已安装伙伴及开发者、版本、许可和公开政策链接；已安装伙伴的名称与真实头像从同一批伙伴记录补齐；没有头像资料时显示中性占位，不按名称推导新的伙伴形象。三种插件详情的信息层级与编辑入口遵守 [UI 标准](../development/ui-cn.md)。说明优先展示面向用户的 Markdown 能力说明。说明与简介来自当前入口版本的原始 README 和清单，不用内置生成指南覆盖第三方正文。原生实现摘要与入口版本分别显示。全局编辑通过底部唯一保存按钮提交展示名称与实际存在的配置，账号连接独立通过官方授权完成；没有配置字段或保留值时不展示空设置表单。伙伴详情展示其固定版本的能力，以及开发者、版本、许可和公开政策链接；启用开关、状态与红色卸载图标统一放在页头右侧操作区，操作错误就近显示。伙伴详情不展示其他伙伴安装和全局共享设置。开发者保留当前入口清单声明，所引用原生包的上游作者与包装维护者通过来源说明分别记录。伙伴入口显示实际安装和自有准备资源，专业编辑与连接测试继续由原模块负责。服务器事实保存在 TanStack Query，插件和独立资源变化复用现有 Core WebSocket 的提交后事件。
