# 资源与记忆

## 伙伴和项目

伙伴资料描述长期职责，档案提供工作方式。项目由伙伴独立管理，包含一个或多个本地目录；删除项目配置保留真实目录和已有聊天。

## 资源库

从主导航打开资源库，在插件、技能和连接器之间切换。插件库展示随软件交付的本地条目；我的插件展示本机已经添加的资源。搜索、视图和分页可以随页面返回恢复。

点击插件安装，先完成必要的共享设置和认证，再选择伙伴。没有选择伙伴时可以仅保存到本机；稍后从我的插件继续。飞书办公首次使用需要配置飞书应用 App ID 和 App Secret，再扫码授权用户身份。业务调用提示缺少权限时，可在同一共享账号面板填写补充权限标识并重新扫码；更换飞书应用也在此处进行。应用配置与用户授权是两个步骤，飞书租户和资源权限仍决定实际可用操作。

所有安装伙伴共用一个插件资源的设置和账号。伙伴可以独立启停、卸载和选择版本；共享设置不兼容旧版时，需要在同一次操作中明确选择受影响伙伴的目标版本，或先卸载不再保留的安装。界面不会自动替其他伙伴升级。

在伙伴详情的资源入口查看真实安装。全局资源先添加到资源库，再明确安装给伙伴；伙伴自己添加的本地资源归该伙伴。卸载全局资源只移除当前伙伴的关系，整体删除会先确认实际影响。

## 技能与连接器

独立技能继续提供 Git/ZIP 导入、文件编辑、版本历史和恢复。连接器继续提供 MCP 配置、信任确认和真实连接测试。插件包含的技能与连接器在插件详情中查看，随插件统一安装和更新。

聊天输入框使用 `/` 选择插件或技能，使用 `#` 选择连接器。插件通常也可由智能体按任务需要自动使用；明确选择会保存在该消息的历史中。

系统 ally 技能随应用提供，用于发现和调用软件能力。连接器保存和首次执行前核对实际命令、地址、凭据与授权范围；测试成功不代表之后每次调用都一定可用。

## 记忆

记忆在伙伴或项目范围中维护。可明确要求伙伴记住、修正或遗忘信息，并查看实际操作结果。没有真实保存回执的口头确认不代表已写入。

保存稳定且可复用的知识，避免密钥、整段聊天和临时进度。语义搜索需要配置 Embedding，未配置时使用关键词检索；有限命中不代表完整知识覆盖。
