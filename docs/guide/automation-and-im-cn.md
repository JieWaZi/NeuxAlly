# 自动任务与 IM

## 自动任务

选择伙伴、团队或工作流，配置定时或本机 API 触发，并检查目录、智能体、权限和参数。可以启停、立即运行、查看记录或轮换 API 密钥。

工作流参数选择固定值、每次 API 提供或适用默认值。使用详情页生成的当前调用说明，不把密钥放进公开文档。输入文件通过上传入口获取引用，结果从对应运行读取。

定时和本机监听依赖应用、设备及连接状态。关闭窗口可继续托盘运行，退出应用、设备休眠或关机会影响执行；状态以实际运行记录为准。

## IM

连接实际消息平台后，为明确聊天授权伙伴或团队，设置执行范围和必要能力。平台连接、聊天授权和工作状态分别展示。

授权聊天可发起工作并接收结果。文件或工作流交付按当前授权执行，未授权聊天不能仅凭连接存在调用能力。发送失败在交付记录中显示，送达状态与执行结果分别确认。

首次配置、平台登录及群聊行为按当前界面的提示进行；不要在 Issue 或日志中公开平台凭据、二维码或原始私人消息。
