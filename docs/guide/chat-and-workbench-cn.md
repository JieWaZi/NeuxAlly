# 聊天与工作台

创建伙伴并维护角色、简介和档案。角色预设只提供创建初值，伙伴之后独立编辑。项目将一个或多个真实本地目录组织在伙伴名下；也可直接选择临时文件夹或使用应用受管目录。

## 对话

发送前检查智能体、账号、模型、权限和目录。首次接纳后固定工作范围，续聊沿用同一聊天身份。实时过程展示说明、思考及工具活动，最终结果和失败保留在消息中。

运行中输入根据能力即时送达或进入临时队列。队列内容未接纳前仍属于待发送输入。停止当前执行后可继续阅读和处理后续工作；重试入口只在服务端判定安全时提供。

## 在对话中使用工作流

在普通伙伴对话的输入框输入 `/`，搜索并选择一个已保存的工作流，再描述本次任务。选择另一个会替换原选择，删除引用即可撤销。智能体根据任务、对话上下文和获准目录准备输入；确实缺少必要信息时再向你询问。团队对话及工作流创作、调整对话不提供这个入口。

发送后，消息中的工作流执行项显示本次运行。点击可在右侧查看准确的运行过程、节点和需要你处理的请求；关闭过程不会停止运行。智能体等待实际结束后总结内容，已确认的最终文件作为消息附件提供打开、预览或下载。工作流已完成时，智能体可能仍在整理答复。

停止对话会同时请求停止本次调用的工作流；在右侧停止工作流后，智能体可读到用户停止原因并结束任务。观察超时或断线不会自动重新运行，已完成的结果也不会被停止操作改写。文件无法交付时保留实际运行结果及不可用说明。

## 工作台

文件、改动、浏览器和终端通过独立标签打开，可分屏并保留各自内容。文件使用原聊天权限和真实路径，切换伙伴或团队成员不改变已打开文件的来源身份。

文件类型按能力提供代码、预览、编辑或下载。HTML 默认代码，Markdown 默认预览；未知或未确认路径保持原文，不假装成可用文件。关闭终端结束该终端会话。

聊天摘要可定位项目改动、上传与生成文件以及团队成员。摘要预览有数量上限，完整列表通过相应入口读取。结果阅读、审批与提示关闭分别操作。
