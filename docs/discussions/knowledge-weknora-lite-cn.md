# WeKnora Lite 对齐边界

当前整理以固定 WeKnora Lite 的流程、方法和提示词为基础，CLI 作为模型服务接入。通用库、资料、Wiki 与图谱沿现有知识核心保存和展示；整理不创建伙伴、聊天或 Execution，也不提供过程查看入口。

当前能力以[知识库架构](../architecture/knowledge-cn.md)为准；[代码来源与适配边界](knowledge-weknora-code-comparison-cn.md)列出核对入口。[本地协议参考](weknora-local-8080-reference.md)仅记录 HTTP 观察，不代表当前服务在线联调通过。
