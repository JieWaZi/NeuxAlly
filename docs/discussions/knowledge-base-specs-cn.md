# 知识库当前交付范围

通用知识库保留库列表、设置、上传、原件预览、手动整理、Wiki 与图谱。知识整理对齐固定 WeKnora Lite，以 CLI 作为模型服务；后台不依赖伙伴、Chat、Execution、聊天日志或候选文件交接。

文档列表统一显示来源状态，失败原因在状态标签悬停提示中查看。删除整理过程查看与聊天入口；原件详情不重复显示整理状态。上传保留原始字节，重建通过独立知识任务执行。

当前职责与协议见[知识库架构](../architecture/knowledge-cn.md)，重写范围见[实施计划](../superpowers/plans/2026-10-21-weknora-lite-cli-model.md)。此前固定 worker、阶段技能接力及整理聊天设计不再作为当前开发要求。
